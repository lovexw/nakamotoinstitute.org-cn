回复 "@Vlad_Roberto：不，我不是程序员。我只知道有更好的方法来做任何事情，而不需要大量的能源消耗和银行。"

想象你坐在一个地堡里。你不知道外面有什么人，也不知道他们的意图。你只收到一些来自陌生人的传入消息，这些消息可能包含任何内容。它们可能只是随机的垃圾信息，也可能是精心构造的用来迷惑你或对你撒谎的消息。你永远不知道。你无法信任任何人。

"货币"或任何其他"社会契约"的问题在于，每个人都应该能够在不信任中介的情况下知道大多数人同意什么（否则中介可以轻易滥用其特殊地位）。如果每个人都投票支持"X"，那么坐在地堡中的你必须以某种方式独立地弄清楚所有其他人确实投票支持了"X"而不是"Y"或"Z"。但请记住：你不能信任任何人的消息，而消息是你从外部世界获得的唯一东西。

当两个提议传到你的地堡——"X"和"Y"时，我们没有可信的参照点来判断哪一个得到了大多数其他人的支持。我们只有"数据本身"来判断我们应该选择哪一个作为主要选项。为了简化问题，我们不对任何一个提议进行主观判断，而只是试图让所有人都同意同一个选项。在比特币的情况下，这是一个合理的假设：每个人都是自己货币的主人，所以只要自己的余额得到尊重，没有人真正关心选择了哪个版本的历史。

那么 X 应该如何区别于 Y，以至于我们可以确信没有人会意外地选择 Y、Z 或 W？第一个属性：这个数据应该是"最近的"。这样我们就知道自己不是停留在某个旧的协议上，而其他人都已经转向了其他事情。第二个属性：任何"最近的"替代方案都应该是无法生产的。因为如果可以生产的话，就总有可能某些人看到了它并接受了那个替代方案。而你无法估计存在多少这样的替代方案以及有多少人接受了它（因为你坐在地堡里，不能信任传入的消息，也不知道你错过了多少消息）。

我们如何定义"无法"？它意味着两种情况之一：要么在逻辑上不可能，要么在实践上（经济上）不可能。如果在逻辑上不可能，那么我们可以通过归纳法提前知道所有未来的协议（就像一条确定性的数字链）。但这行不通，因为我们必须首先就起点达成某种协议。所以我们最终需要的是实践上的不可能性。换句话说，我们需要以下条件：

**消息 X 应该是可证明为最近的，且替代方案在实践中无法生产。**

实践上的不可能性可以用"机会成本"来重新表述：物理资源是有限的，这些资源应该已经被大量分配给了 X 而非 Y，这样我们就能看到 X 吸走了所有替代方案的资源。因为如果它没有做到这一点，那么就存在巨大的不确定性——剩余资源是被用于替代方案 Y，还是它们根本不干扰投票过程？有没有可能 X 没有吸走大量资源，而替代方案仍然无法生产？那将意味着 X 从系统的任何先前状态在逻辑上推出，根本不需要投票过程。

因此：消息 X 应该是可证明为最近的，并且应该已经消耗了可证明的大量资源，这些资源足够庞大，以至于没有足够的剩余资源在任何替代方案 Y 中在合理短的时间范围内生产出来。此外，消息 X 应该始终是"最近的"，并且始终压倒任何替代方案。因为我们无法可靠地比较"旧的"消息：Y 是一条刚刚才送达的"旧"消息，还是它在 X 上花费的资源被释放之后才刚刚被生产的？

这在逻辑上引导我们得出以下结论：我们应该只接受附带最大工作量证明的消息，并且该工作量证明应该是有史以来最大的，这样就不会有任何可能在短时间窗口内生产出替代方案的可能性。而且该工作量证明必须不断地被加强，否则先前共识的价值会迅速消退，因为替代方案的机会也在增长。

昂贵的、高度专业化的计算机农场是达成共识的最可靠方式。如果我们使用非专业化资源，就更难衡量它们中的大多数是否确实被用于工作量证明计算。通过观察到在一个非常特定的、容易观察的经济领域中发生了大量的工作，我们可以估算出生产一个同样困难的替代消息的成本。在比特币矿场的情况下，这样的替代方案将需要非常昂贵和复杂的生产链——需要要么在与使用芯片代工厂的公司竞争中胜出，要么在地球上最具成本效益的地点（拥有最便宜的电力、最寒冷的气候、最低延迟的连接等）建造专用数据中心。

## 结论

如果以非信任方式达成共识在实践中确实是可能的，那么它只能通过工作量证明方案和高度专业化的昂贵生产链来实现。此外，共识只在很短的时间内有价值，因此必须不断加强。
