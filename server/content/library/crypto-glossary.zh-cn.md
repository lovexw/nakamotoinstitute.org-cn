### 密码学的主要分支（我们的看法）

_（这些部分将在上下文中引入术语，但不会给出完整的定义）_

加密
: 消息的隐私保护
: 使用密码和编码来保护消息的机密性
: DES 是最常见的对称密码（加密和解密使用相同的密钥）
: RSA 是最常见的非对称密码（加密和解密使用不同的密钥）

签名与认证
: 证明你是谁
: 证明你签署了某份文件（而不是其他人）

不可追踪邮件
: 不可追踪地发送和接收邮件及消息
: 重点：击败窃听者和流量分析
: DC 协议（用餐密码学家协议）

密码学投票
: 重点：投票箱匿名性
: 投票凭证
: 重复投票、安全性、鲁棒性、效率等问题

数字现金
: 重点：交易和购买的隐私
: 不可关联凭证
: 盲签名票据
: "数字硬币"可能无法实现

密码无政府主义
: 利用上述技术规避政府、绕过税收等
: 用技术方案解决政府过度干预的问题

## 术语表

agoric systems（自由市场系统）
: 开放的、自由的市场系统，其中自愿交易是核心。

Alice and Bob（爱丽丝和鲍勃）
: 密码学协议通常通过考虑 A 方和 B 方——即 Alice 和 Bob——执行某个协议来更加清晰地阐述。窃听者 Eve、证明者 Paul 和验证者 Vic 是其他常见的角色名称。

ANDOS（全有或全无的秘密披露）
: All or nothing disclosure of secrets。

anonymous credential（匿名凭证）
: 一种凭证，它断言某种权利或特权或事实，而不透露持有者的身份。这与加州驾驶执照不同。

asymmetric cipher（非对称密码）
: 同公钥密码系统。

authentication（认证）
: 验证身份或凭证的过程，以确保你确实是你所声称的身份。

biometric security（生物识别安全）
: 一种使用指纹、视网膜扫描、掌纹或其他个人物理/生物特征的认证方式。

bit commitment（比特承诺）
: 例如，抛硬币后对结果值做出承诺，且不能更改结果。blob（比特承诺盒子）是用于此目的的密码学原语。

blinding, blinded signatures（盲化，盲签名）
: 签名者不记得自己曾做出过的签名。盲签名始终是一种协作协议，签名的接收者向签名者提供盲化信息。

blob（比特承诺盒子）
: 相当于密码学中的上锁箱子。一种用于比特承诺的密码学原语，具有以下属性：blob 可以表示0或1；其他人无法通过观察判断它是0还是1；blob 的创建者可以"打开"blob 以揭示内容；没有 blob 可以既是0又是1。一个例子是被手盖住的翻转硬币。

channel（信道）
: 消息传输的路径。信道可以是安全的或不安全的，可能有窃听者（或敌人、破坏者等）会修改消息、插入和删除消息等。密码学是保护在不安全信道上的通信的手段。

chosen plaintext attack（选择明文攻击）
: 一种攻击方式，密码分析师可以选择要加密的明文，例如当加密机或算法掌握在密码分析师手中时。

cipher（密码）
: 一种秘密的书写形式，使用字符或符号的替换或置换。

ciphertext（密文）
: 明文加密后的结果。

code（编码）
: 一种受限的密码系统，其中消息的单词或字母被从密码本中选取的其他单词替换。不属于现代密码学，但仍然有用。

coin flipping（掷币）
: 一种重要的密码学原语或协议，其中可以进行等同于抛公平硬币的操作。使用 blob 实现。

collusion（共谋）
: 多个参与者合作推导发送者或接收者的身份，或破解密码。大多数密码系统对某些形式的共谋是敏感的。例如，实现 DC 网络的大部分工作涉及确保共谋者无法隔离消息发送者，从而追踪邮件的来源和目的地。

computationally secure（计算安全性）
: 密码无法用现有计算资源破解，但理论上可以用足够的计算资源破解。与无条件安全相对。

countermeasure（对策）
: 为挫败攻击者而采取的措施。

credential（凭证）
: 关于某个实体的事实或断言。例如，信用评级、护照、声誉、税务状况、保险记录等。在当前系统下，这些凭证越来越多地被交叉关联。盲签名可用于创建匿名凭证。

credential clearinghouse（凭证清算所）
: 银行、信用机构、保险公司、警察部门等，它们关联记录并决定记录的状态。

cryptanalysis（密码分析）
: 攻击和破解密码及相关密码系统的方法。密码可能被破解，流量可能被分析，密码可能被破译。计算机当然是必不可少的。

crypto anarchy（密码无政府主义）
: 在加密、不可追踪电子邮件、数字假名、密码学投票和数字现金部署之后的经济和政治系统。这是对"crypto"的双关语，意为"隐藏的"，就像 Gore Vidal 称 William F. Buckley 为"crypto fascist"（秘密法西斯主义者）一样。

cryptography（密码学）
: cryptology 的另一个名称。

cryptology（密码科学）
: 编写、发送、接收和破译秘密消息的科学和研究。包括认证、数字签名、消息隐藏（隐写术）、密码分析和其他几个领域。

cyberspace（赛博空间）
: 电子领域、网络和计算机生成的空间。有人说它是《神经漫游者》中描述的"共识现实"。有人说它是电话系统。还有人——有工作要做。

DC protocol, or DC-Net（DC协议或DC网络）
: 用餐密码学家协议。DC 网络使用多个参与者通过 DC 协议进行通信。

DES
: 数据加密标准，1977年由国家标准局（现 NIST）提出，由国家安全局协助。基于 IBM 的 Horst Feistel 开发的"Lucifer"密码，DES 是一种密钥密码系统，将64位数据块通过多次置换循环，由56位密钥控制路由。"扩散"和"混淆"结合形成一种至今尚未被密码分析的密码（参见"DES 安全性"）。DES 用于银行间转账，作为几种基于 RSA 的系统内部的密码，也可用于个人电脑。

DES, Security of（DES的安全性）
: 许多人猜测 NSA 在 DES 中放置了陷门（或后门）以允许其读取 DES 加密的消息。这尚未被证实。已知的是，原始的 Lucifer 算法使用128位密钥，而此密钥长度被缩短为64位（56位加8位奇偶校验位），从而使穷举搜索变得更加容易（据目前所知，暴力搜索尚未完成，尽管在今天应该是可行的）。Shamir 和 Biham 使用了一种称为"差分密码分析"的技术来减少选择明文攻击所需的穷举搜索（但对普通 DES 没有影响）。

differential cryptanalysis（差分密码分析）
: Shamir-Biham 用于密码分析 DES 的技术。在选择明文攻击中，他们将要尝试的 DES 密钥数量从约2^56减少到约2^47或更少。但请注意，攻击者很少能对 DES 系统发起选择明文攻击。

digital cash, digital money（数字现金，数字货币）
: 以电子方式转移价值（货币或其他）的协议。数字现金通常指匿名系统。数字货币系统可用于实现任何守恒的量，如积分、质量、美元等。数字货币系统有多种变体，从 VISA 卡号到盲签名数字硬币。这个主题太大，无法在单个术语表条目中涵盖。

digital pseudonym（数字假名）
: 基本上是一个"密码身份"。一种让个人与各种组织建立账户而不透露超过其愿意分享的信息的方式。用户可以拥有多个数字假名，一些只使用一次，一些使用多年。理想情况下，假名只能在持有者的意愿下被关联。在最简单的形式中，公钥可以作为数字假名，不需要与物理身份关联。

digital signature（数字签名）
: 类似于文件上的手写签名。对消息的修改只有签名者才能进行，但所有人都能识别。可用于远程签约，具有法律效力。

digital timestamping（数字时间戳）
: 数字公证人的功能之一，其中某些消息（歌曲、剧本、实验室记录本、合同等）被盖上一个不易伪造的时间戳。

dining cryptographers protocol（用餐密码学家协议，又称 DC 协议，DC 网络）
: 由 David Chaum 发明的不可追踪消息发送系统。以计算机科学中的"用餐哲学家"问题命名，参与者形成电路并传递消息，使得除非共谋，否则无法推导出消息来源。在最简单的层面上，两个参与者之间共享一个密钥。其中一个通过将消息与密钥进行按位异或运算来发送实际消息，而另一个只发送密钥本身。这对参与者的实际消息是通过将两个输出进行异或运算获得的。然而，除了这对参与者之外没有人知道原始密钥，因此实际消息无法追溯到任何一个参与者。

discrete logarithm problem（离散对数问题）
: 给定整数 a、n 和 x，找到某个整数 m 使得 a^m mod n = x（如果 m 存在）。模幂运算——即 a^m mod n 部分——很简单（且有专用芯片可用），但逆问题被认为非常困难。因此，推测模幂运算是一个单向函数。

DSS, Digital Signature Standard（数字签名标准）
: NIST（国家标准与技术研究所，NBS 的继任者）最新的数字签名标准。基于 El Gamal 密码，一些人认为它较弱，是 RSA 签名方案的低劣替代品。

eavesdropping, or passive wiretapping（窃听或被动窃听）
: 在不被发现的情况下拦截消息。无线电波可能被截获，电话线路可能被搭线窃听，计算机的射频辐射可能被检测到。即使是光纤线路也可以被窃听。

factoring（因式分解）
: 一些大数很难分解。推测不存在可行的——即"简单的"，复杂性低于指数级的——因式分解方法。RSA 是否可以比通过因式分解模数更容易地被破解也是一个开放性问题（例如，公钥可能揭示某些信息从而简化问题）。有趣的是，虽然因式分解被认为是"困难的"，但它不知道是否属于 NP 困难问题类。Janek 教授发明了一种因式分解装置，但他被认为是虚构的。

information-theoretic security（信息论安全）"不可破解的"
: 安全性，其中任何程度的密码分析都无法破解密码或系统。一次性密码本就是一个例子（前提是密码本没有丢失、被盗或重复使用）。与无条件安全相同。

key（密钥）
: 加密或解密消息所需的信息。密钥可能被窃取、购买、丢失等，就像物理钥匙一样。

key exchange, or key distribution（密钥交换或密钥分发）
: 在对称密码中与某方共享密钥的过程，或在非对称密码中分发公钥的过程。一个重要问题是密钥必须可靠地交换且不被妥协。Diffie 和 Hellman 设计了一种基于离散对数问题的方案。

known-plaintext attack（已知明文攻击）
: 在已知明文-密文对的情况下对密码进行密码分析。此攻击搜索未知密钥。与选择明文攻击相对照——在后者中，密码分析师还可以选择要加密的明文。

mail, untraceable（不可追踪邮件）
: 一种可发送和接收邮件而不可追踪或观察的系统。匿名接收邮件可以通过广播加密形式的邮件来实现。只有预期的接收者（其身份或真名可能对发送者来说是未知的）才能解密消息。匿名发送邮件显然需要混合器或使用用餐密码学家（DC）协议。

minimum disclosure proofs（最小披露证明）
: 零知识证明的另一个名称，由 Chaum 倡导。

mixes（混合器）
: David Chaum 用来描述一个执行混合或去相关功能的术语——即将传入和传出的电子邮件消息进行去关联。该盒子还剥去外层信封（即用其私钥解密）并将消息重新发送到内信封上的地址。抗篡改模块可用于防止作弊和强制披露传入和传出邮件之间的映射关系。一系列多次重发有效地使追踪发送和接收变得不可能。与软件版本 DC 协议形成对比。

modular exponentiation（模幂运算）
: 将一个整数提升到另一个整数的幂，再对某个整数取模。对于整数 a、n 和 m，即 a^m mod n。例如，5^3 mod 100 = 25。模幂运算可以通过一系列位移和加法快速完成，已设计出专用芯片。另见离散对数。

National Security Agency (NSA)（国家安全局）
: 最大的情报机构，负责制作和破解密码、截获通信以及确保美国计算机的安全。总部位于马里兰州米德堡，在世界各地设有许多监听站。NSA 资助密码学研究并就密码学事务向其他机构提供建议。NSA 曾经显然拥有世界上顶尖的密码学家，但情况可能不再如此。

negative credential（负面凭证）
: 一种你拥有但不想让他人知道的凭证，例如破产申请。负面声誉的正式版本。

NP-complete（NP完全）
: 一大类困难的问题。"NP"代表非确定性多项式时间，这是一类被认为通常不存在可行算法来求解的问题。如果任何其他 NP 问题都可以归约为该问题，则该问题是"完全的"。许多重要的组合和代数问题是 NP 完全的：旅行商问题、哈密顿回路问题、字问题等等。

oblivious transfer（遗忘传输）
: 一种涉及比特的概率传输的密码学原语。发送者不知道比特是否被接收。

one-time pad（一次性密码本）
: 一串随机选择的比特或符号，与明文消息结合以产生密文。这种结合可以是字母移位、按位异或等。接收者也有一次性密码本的副本，可以轻松恢复明文。只要密码本只使用一次然后销毁，且窃听者无法获取，该系统就是完美安全的，即具有信息论安全性。密钥（密码本）的分发显然是一个实际问题，但可以考虑使用 CD-ROM。

one-way function（单向函数）
: 在一个方向上容易计算但难以找到任何逆函数的函数，例如模幂运算，其逆问题被称为离散对数问题。比较陷门单向函数这一特殊情况。单向运算的一个例子是乘法：将两个100位的素数相乘产生一个200位的数很容易，但对那个200位数进行因式分解却很难。

P ?=? NP
: 无疑是复杂性理论中最重要的未解决问题。如果 P = NP，那么我们今天所知的密码学就不存在了。如果 P = NP，所有的 NP 问题都是"简单的"。

padding（填充）
: 发送额外的消息以迷惑窃听者并击败流量分析。也指在对消息加密前添加随机比特。

plaintext（明文）
: 又称 cleartext，要被加密的文本。

Pretty Good Privacy (PGP)
: Phillip Zimmerman 实现的 RSA，最近升级到2.0版，具有更强大的组件和几项新功能。RSA Data Security 威胁了 PZ，所以他不再参与开发。2.0版由一个非美国黑客联盟编写。

prime numbers（素数）
: 除了自身和1之外没有其他因子的整数。素数的数量是无限的。大约有1%的100位十进制数是素数。由于宇宙中大约有10^70个粒子，所以宇宙中每个粒子大约对应10^23个100位素数！

probabilistic encryption（概率加密）
: 由 Goldwasser、Micali 和 Blum 提出的一种方案，允许同一明文对应多个密文，即对同一明文重复加密可能产生许多不同的密文。这可以防止对 RSA 的某些类型的已知密文攻击。

proofs of identity（身份证明）
: 证明你是谁，无论是你的真名还是你的数字身份。通常，拥有正确的密钥就足以证明（请保管好你的密钥！）。一些工作已经在"是一个人"的凭证颁发机构方面取得了进展，使用所谓的 Fiat-Shamir 协议……可以将其视为一种颁发不可伪造的数字护照的方式。物理身份证明可以通过生物识别安全方法完成。零知识身份证明除了证明身份确实如所声称的那样之外，不透露任何其他信息。这在计算机访问、密码等方面有明显的用途。

protocol（协议）
: 解决某些问题的正式程序。现代密码学主要是研究解决许多问题的协议，如掷币、比特承诺（blob）、零知识证明、用餐密码学家等。

public key（公钥）
: 公开分发给潜在消息发送者的密钥。它可以在类似电话簿的目录中发布或以其他方式发送。一个主要问题是此公钥的有效性，以防范欺骗或冒充。

public key cryptosystem（公钥密码系统）
: 密码学的现代突破，由 Diffie 和 Hellman 设计，还有其他人的贡献。使用陷门单向函数，使任何人只要有"公钥"就可以进行加密，但只有"私钥"的持有者才能解密。涵盖公钥加密、数字签名、数字现金以及许多其他协议和应用。

public key encryption（公钥加密）
: 使用现代密码学方法提供消息的安全性和认证。RSA 算法是使用最广泛的公钥加密形式，尽管存在其他系统。公钥可以自由发布（例如在类似电话簿的目录中），而相应的私钥则被严格保管。

public key patents（公钥专利）
: MIT 和斯坦福由于 Rivest、Shamir、Adleman、Diffie、Hellman 和 Merkle 的工作，组建了 Public Key Partners 来许可各种公钥、数字签名和 RSA 专利。这些专利在1980年代初期获得授权，将在1998年至2002年间到期。PKP 已许可位于加利福尼亚州红木城的 RSA Data Security Inc.，由后者处理销售等事务。

quantum cryptography（量子密码学）
: 基于量子力学原理的系统。窃听者会改变系统的量子状态从而被检测到。由 Brassard 和 Bennett 开发，目前仅进行了小规模的实验室演示。

reputations（声誉）
: 某个实体积累的正面和负面关联及判断的记录。信用评级、学术证书和可信度都是例子。数字假名将根据行为、他人的意见等积累这些声誉凭证。在密码无政府主义中，声誉系统和自由市场系统将至关重要。关于基于声誉的系统如何运作、凭证如何买卖等问题，有许多有趣的议题。

RSA
: 主要的公钥加密算法，由 Ron Rivest、Adi Shamir 和 Kenneth Adleman 开发。它利用大数因式分解的困难性来创建私钥和公钥。1978年首次发明，至今仍是现代公钥系统的核心。它通常比 DES 慢得多，但专用的模幂运算芯片可能会加快其速度。一种流行的加速方案是使用 RSA 传输会话密钥，然后使用 DES 等高速密码来加密实际的消息文本。

    **描述：** 设 p 和 q 是大素数，通常超过100位。设 n = pq，并找到某个与(p - 1)(q - 1)互素的 e。数集 p、q 和 e 是 RSA 的私钥。数集 n 和 e 构成公钥（注意，知道 n 不足以轻松找到 p 和 q……这是因式分解问题）。消息 M 通过计算 M^e mod n 来加密。私钥持有者可以利用数论结果来解密加密消息，如下所示。计算整数 d 使得 ed = 1（mod (p - 1)(q - 1)）。欧拉证明了一个定理：M^(ed) = M mod n，因此 M^(ed) mod n = M。这意味着在某种意义上，整数 e 和 d 互为"逆元"。[如果不清楚，请参阅有关公钥加密的众多教材和文章。]

secret key cryptosystem（密钥密码系统）
: 在通信链路的两端使用相同密钥来加密和解密流量的系统。也称为对称系统或单密钥系统。与公钥密码系统相对。

smart cards（智能卡）
: 嵌入信用卡中的计算机芯片。它们可以存储现金、凭证、密码密钥等。通常这些卡具有一定程度的抗篡改性。智能卡可以执行密码交易的一部分或全部。执行部分可能意味着验证更强大计算机（例如 ATM 中的计算机）的计算。

spoofing, or masquerading（欺骗或伪装）
: 冒充另一个用户。用于窃取密码、修改文件和盗窃现金。数字签名和其他认证方法有助于防止这种情况。公钥必须经过验证和保护，以确保他人不会用自己的公钥替代，从而让用户在不知情的情况下使用。

steganography（隐写术）
: 密码学中处理隐藏消息和掩盖谁在发送及接收消息的部分。消息流量通常被填充以减少消息突然开始时会产生的信号。

symmetric cipher（对称密码）
: 同私钥密码系统。

tamper-responding modules, tamper-resistant modules (TRMs)（抗篡改模块）
: 封装的盒子或模块，难以打开，需要大量探测，通常会留下充分的证据表明发生了篡改。使用各种保护技术，如芯片上的特殊金属或氧化层、装甲涂层、嵌入的光纤以及其他措施来阻碍分析。俗称为"防篡改盒子"。用途包括：智能卡、核武器触发器、密钥保管器、ATM 等。

tampering, or active wiretapping（篡改或主动窃听）
: 干涉消息并可能修改它们。这可能会危及数据安全、帮助破解密码等。另见欺骗。

token（代币）
: 某种表示，如身份证、地铁代币、货币等，表示拥有某种属性或价值。

traffic analysis（流量分析）
: 通过分析数据包、数据包频率等来确定谁在发送或接收消息。隐写术的一部分。通常通过流量填充来处理。

transmission rules（传输规则）
: 在 DC 协议中确定谁可以发送消息以及何时发送的协议。这些规则是防止信道碰撞和故意干扰所必需的。

trap messages（陷阱消息）
: DC 网络中的虚假消息，用于捕获干扰者和破坏者。这些消息不包含私人信息，事先以 blob 形式发布，以便日后可以打开陷阱消息来揭露破坏者。（这里有许多策略可以探索。）

trap-door（陷门）
: 在密码学中，一段秘密信息，允许私钥持有者对一个通常难以求逆的函数进行求逆。

trap-door one way functions（陷门单向函数）
: 在正向和反向都容易计算的函数，但公开正向计算算法不会提供如何反向计算的信息。更简单地说，对于除秘密信息持有者之外的所有人来说，陷门单向函数都是单向的。RSA 算法是此类函数最著名的例子。

unconditional security（无条件安全）
: 同信息论安全，即除密钥丢失或被盗外不可破解。

unconditionally secure（无条件安全）
: 无论截获多少密文都不足以破解密码，如使用一次性密码本加密。与计算安全相对照。

voting, cryptographic（密码学投票）
: 已设计出多种匿名、不可追踪的投票方案。投票方案应具有以下属性：投票的隐私性、投票的安全性（不能多次投票）、对干扰或破坏的鲁棒性、可验证性（投票者对结果有信心）和效率。

zero knowledge proofs（零知识证明）
: 在不传达实际证明任何知识的情况下进行的证明。证明者 Peggy 向怀疑者 Sid 证明她确实掌握某项知识，而实际上不揭示任何该知识。这对于计算机访问很有用，因为窃听者或不诚实的系统管理员无法窃取所传递的知识。也称为最小披露证明。可用于证明拥有某种属性或凭证（如年龄或投票资格），而不透露个人信息。
