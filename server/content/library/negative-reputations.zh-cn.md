一个重要且普遍的问题似乎是为负面行为源标记标签以供未来识别。该标签可用于公开共享的负面信息（例如信用评级）或私下保存的信息（例如屏蔽名单）。行为源可能是非人类的（例如识别病毒模式以进行病毒扫描）。当行为源具有适应性和自利性时，它有动机欺骗标记：债务人改名以逃避还债，病毒打乱其模式以避免被扫描，等等。如果标签携带的正向声誉大于零（即新来者的声誉为零），这种动机就消失了，声誉的负面一面——不良声誉——就必须被承担。

数字凭证系统是否能促进此类负面声誉管理？

特定服务的声誉，即本地化名声誉，可能无法实现这种对负面声誉的追踪。如果一个本地化名积累的负面凭证多于正面凭证，它可以简单地用一个新来者的本地化名替代该服务，而不会损害行为源其他本地化名的正面声誉资本。恶意源可以持续伪装成无辜的新来者。交易对手方则失去了确定先前恶意行为历史的能力——屏蔽名单、病毒扫描、信用评级等均会失效。

[Chaum 式凭证](/library/security-without-identification/)还赋予凭证持有者控制其本地化名之间凭证转移的权力，从而创造了展示正面凭证和隐藏负面凭证的激励。为了纠正这一点，交易对手方可以要求"非负面凭证"（形式如"Alice 在我记录的区域 X 的多次交易中从未做过坏事 x、y、z"）。非负面凭证仅限于可以良好追踪的领域。信用评级可能是一个这样的领域，只要一个人的大部分信用交易是通过与真实身份关联的本地化名进行的。

在 Chaum 式凭证不适用的地方，我们可以将进入门槛提高到高于新来者的水平。这给了我们两个明确定义的声誉点以供在一个相当主观的尺度上比较：参与门槛和新来者声誉。两者在选择是否与某个化名参与活动的一方眼中都是主观的。

参与门槛高于新来者声誉与我们期望的目标——能够重新开始——相矛盾。更何况，除非先前的化名及其正面声誉与新化名相关联，否则先驱者也无法起步，机构本身就无法启动。机构成长也是如此。

将各种交易结果捆绑在一起的标签——全局化名，即通用 ID，即"真名"——似乎为各方携带其负面凭证提供了最大的激励。大多数人已经在某些领域积累了足够的正面声誉，以至于他们几乎不可能以新来者的身份重新开始其全部生活。

当负面凭证不仅仅是用于避免与某方进行某项活动，而是用于对其实施报复时，就出现了一个大问题。报复可能采取某种非暴力的在线形式，如诽谤、拒绝服务攻击等，但最令人担忧的报复形式是暴力的物理攻击。我们能否拥有这样的数字标签——在通过数字世界追踪负面行为源的同时，严格不与任何形式的物理位置数据相关联？遗憾的是，我们有几个重要的系统，如手机、送货地址等，提供了这种关联。

问题可能变成决定以下三个维度中哪些最重要，以及它们如何权衡：

- 通过追踪从而避免负面行为源所获得的收益
- 一个非暴力数字世界所获得的收益（即一个虚拟领域，在其中任何数字行动都不会产生暴力物理后果）
- 将物理世界和数字世界划分为不同 ID 系统的不便（也许还有不切实际之处）（更现实地说，是数字世界的某个"纯粹"子集，与定位设备、物理运输信息等完全隔离）

还要记住，在实践中，这些主要由从当前状态演化的市场来评估，而非由抽象的伦理哲学来评估。

Robin Hanson 指出，在一个使用全局化名的世界中，使用本地化名可能传递了隐藏负面凭证的信号，因此全局化名的使用成为一种均衡。本地化名的另一个问题是，我们的关系通常无法整齐地划分为标准的服务类型，即使可以，我们可能也想将它们扩展到新的领域。本文作者建议，至少，我们应在与交易对手方的关系变得更密切、风险共担更大时，逐步向对方揭示更多的本地化名。

虽然全局化名均衡可能适用于我们的许多关系，但在许多领域中，本地化名的[亲密性](/smart-contracts-glossary/#privity)优势可能超过无法区分新来者与恶意者的成本。（所谓"亲密性"，我指的是保护关系免受恶意第三方侵害的整个一般任务；保密和防止财产被盗是亲密性的两个例子。）例如，www.firefly.com 的偏好追踪服务通过使用化名提高了参与度，且几乎不受到恶意者的威胁。另一方面，信用交易通常要求提供身份信息，因为合同风险通常超过亲密性的好处。

全局化名公钥在亲密性方面有许多缺陷，可能是追踪负面声誉的最佳方式，但绝非万能药。在基于 ID 的密钥系统中存在一个重要的难题：当旧密钥已被或可能被他人滥用时获取新密钥的能力（密钥撤销），与他人确保他们在和同一个人打交道的能力之间的冲突。这也可能为各方提供选择性地揭示正面凭证而隐藏负面凭证的机会。例如，信用评级不良的人可以撤销该评级分发所依据的密钥并创建新密钥，同时选择性地将其正面凭证更新到新密钥（例如让其母校创建新文凭）。密钥撤销[机构](/distributing-authorities-and-verifying-their-claims/)可以与信用评级机构合作以避免这种负面历史的抹除，但这赋予了它们更多的集中控制权——不仅是对 ID 的控制，还包括与这些 ID 关联的重要声誉要素。这进一步违反了权力分立和职责分离原则，为欺诈性的 ID 发放或撤销以及欺诈性的声誉信息传递提供了更多机会。

目前美国的通用（非密码学）密钥——社会安全号（SSN）——非常难以撤销。改名字都比这容易。这项政策恐怕并非偶然，因为全局化名识别的最大经济收益在于追踪负面声誉，而撤销可以使其失效。只要 SSN 是一个共享的数据库密钥，不用于安全地面向无特征交易的身份验证，那么除了不受欢迎的负面历史抹除之外，几乎没有撤销的需要。将必须可撤销的秘密认证密钥与公开的通用 ID 结合起来是相当有问题的。
