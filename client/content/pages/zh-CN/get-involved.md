中本聪研究院致力于推进和保存比特币的历史、经济学与技术知识。我们相信，比特币是全人类迈向和平与繁荣未来的钥匙，但它的成功需要人们真正理解它。在您的帮助下，我们可以让未来的比特币使用者珍视这项技术，并见证它发挥出全部潜力。欢迎通过以下方式参与：

## 捐赠

中本聪研究院是一家非营利组织，依靠像您这样的支持者的慷慨捐助运转。捐赠用于支持我们的日常运作，例如维护本网站、制作教育内容以及组织活动。如果您认可我们的工作价值，请考虑进行一笔可抵税的捐赠。您可以在我们的[捐赠页面](/donate)通过比特币、闪电网络或信用卡捐款。

## 代码

作为开源项目，中本聪研究院欢迎志愿开发者参与贡献我们的代码库。我们的全部代码都托管在 [GitHub](https://github.com/NakamotoInstitute) 上。如果您具备 Web 开发或设计技能，并希望帮助改进本网站，我们将非常感激您的贡献。入门请查看 GitHub 上的[我们的仓库](https://github.com/NakamotoInstitute/nakamotoinstitute.org)以及当前的待办 issue 和功能请求列表。如有任何疑问，欢迎直接提交 issue 或 Pull Request。

## 翻译

比特币属于全世界，我们的使命也是。我们希望让每个人都能获取并理解比特币知识。为此，我们正在努力将我们的图书馆及其他内容翻译成尽可能多的语言。

如果您精通英语和另一种语言，我们非常欢迎您协助翻译。要加入我们的翻译社区，请填写[这份表单](https://forms.gle/QbaYmkz1mJwBbErf6)，说明您的意向和语言能力。我们会与您联系并告知后续步骤，对您提供的任何翻译协助我们都深表感谢。

您也可以直接在 [GitHub](https://github.com/NakamotoInstitute/nakamotoinstitute.org) 上通过 Pull Request 提交译文，或填写表单说明您的意向和语言能力。我们会与您联系并告知后续步骤，对您提供的任何翻译协助我们都深表感谢。
